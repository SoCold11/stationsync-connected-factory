StationSync — Project Import, Setup & Functional Validation

Project context

I am developing StationSync, a Connected Factory software application focused on helping manufacturing engineers identify, investigate, and safely reconcile inconsistencies between physical manufacturing equipment and digital factory systems.

The application was designed through a structured product-management process covering problem discovery, user research, user journeys, product requirements, technical architecture, and MVP development.

IMPORTANT: The attached ZIP already contains the application source code. This is an existing project, not a request to generate a new application from scratch.

Your immediate responsibility is to import, configure, run, and validate the existing application while preserving its architecture, functionality, and design.

1. Application overview

StationSync enables manufacturing engineers to:

Monitor production stations, equipment, and synchronization status.

Compare approved station assignments with physical observations and AMS/MES records.

Detect and investigate discrepancies.

Record physical asset observations.

Review, authorize, and execute targeted reconciliation actions.

Verify updates and track synchronization results.

Handle partial system failures and retry unsuccessful operations.

Reconfigure approved station assignments.

Review an audit trail of changes and synchronization attempts.

The primary workflow is:

Observe → Compare → Investigate → Reconcile → Verify

Station configuration is a secondary supporting workflow.

An essential product principle is that a physical observation does not automatically authorize a change to approved configuration. The application must distinguish between observed, expected, and recorded states.

Validation safeguards

An unauthorized physical movement does not automatically update approved configuration.

Failure recovery

The simulated MES failure can be triggered.

A partial failure does not falsely report complete synchronization.

Station configuration and persistence

An approved station assignment can be changed.

Station reconfiguration does not automatically overwrite physical observations or AMS/MES records.

Audit history is maintained.

Refreshing the application preserves saved data.

Resetting the demo restores its initial state.
